Uso docente

Cada laboratorio funciona como página normal y como vista compacta 16:9 añadiendo ?embed=1. Las capturas para PowerPoint se generan desde el modo incrustado a 1280×720.

El código HTML/CSS/JavaScript se publica bajo 0BSD. El contenido docente propio se publica bajo CC0 1.0 Universal. Las diapositivas completas se distribuyen desde el aula virtual.
