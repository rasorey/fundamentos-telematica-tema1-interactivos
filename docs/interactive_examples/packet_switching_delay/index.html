Fórmulas usadas

Ttx paquete = Lpaquete / R

Overhead total = número de paquetes · tamaño de cabecera

Eficiencia útil = datos útiles / bits totales transmitidos

Goodput aproximado = datos útiles entregados / tiempo total

Llegada último paquete ≈ H · Tprop + (H + P - 1) · Ttx_paquete, aproximación simplificada sin colas ni procesamiento salvo que actives esos parámetros.
