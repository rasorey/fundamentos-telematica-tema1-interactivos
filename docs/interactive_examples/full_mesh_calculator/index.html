Malla completa

Explora cómo crecen enlaces e interfaces cuando todos los nodos se conectan directamente entre sí.

Parámetros

Antes de cambiar parámetros, predice:

Si duplicas N, ¿se duplican los enlaces o crecen más rápido?

28enlaces
7interfaces por nodo
56interfaces totales
Fórmulas usadas

Enlaces = N · (N - 1) / 2
Interfaces por nodo = N - 1
Interfaces totales = N · (N - 1)

Interpretación

La malla completa da conexión directa entre todos los pares, pero enlaces e interfaces crecen cuadráticamente.
