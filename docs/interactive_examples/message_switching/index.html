Conmutación de mensajes

Simula el paso de un mensaje completo por nodos intermedios con buffers y colas.

Parámetros

Predice:

¿Qué ocurre si el mensaje completo no cabe en el buffer del nodo?

Almacenamiento y reenvío

-transmisión por salto
-retardo total aprox.
-ocupación de buffer
-paquetes aprox.

Fórmulas usadas

Tsalto ≈ Ttx_mensaje + Tcola + Tprocesamiento. En conmutación de mensajes, cada nodo espera el mensaje completo antes de reenviarlo.

Reto · retardo total aproximado

Pulsa “Nuevo reto” para calcular el retardo de almacenamiento y reenvío.

Interpretación

Pregunta de reflexión

¿Por qué almacenar el mensaje completo simplifica el reenvío, pero penaliza retardo y memoria?
