# Créditos de imágenes

No se han incorporado imágenes, fotografías, iconos o recursos externos al sitio.

Las figuras técnicas de los simuladores se dibujan con SVG generado por código propio y se consideran contenido docente original publicado bajo CC0 1.0 Universal. El código que las genera está publicado bajo 0BSD.

Las capturas incluidas en `docs/assets/screenshots/` son capturas propias de estos mismos simuladores, tanto en modo normal como en modo incrustado, generadas para documentación y para su reutilización en las diapositivas del aula virtual. Se publican bajo CC0 1.0 Universal.
