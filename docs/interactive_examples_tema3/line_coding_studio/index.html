Qué observar

  • NRZ puede tener largas zonas sin transición.
  • NRZI codifica mediante cambios o ausencia de cambios.
  • Manchester introduce una transición por bit, útil para sincronismo.
  • B8ZS/HDB3 sustituyen ceros largos para recuperar transiciones.
