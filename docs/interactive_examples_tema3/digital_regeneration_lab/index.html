Regeneracion digital

Degrada una senal digital, decide bits por umbral y observa cuando el regenerador reconstruye la forma ideal o incorpora un error.

Controles

Solo 0 y 1, maximo 16 bits.
0 %BER
0/8bits erroneos
1.00 Vmargen minimo

El regenerador no conserva la forma ruidosa: decide y reconstruye.

Original, recibida, decision y regenerada

Que observar

  • La senal digital puede llegar degradada por ruido y atenuacion.
  • El receptor decide 0 o 1 comparando muestras con un umbral.
  • Si una muestra cruza el umbral equivocado, el regenerador reconstruye un bit erroneo.

Reto

Sube el ruido hasta provocar el primer error. ¿Que muestra cruza el umbral?
