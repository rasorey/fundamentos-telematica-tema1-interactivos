Multiplexación por puertos

Comprueba cómo IP elige la máquina y TCP/UDP con puerto eligen la aplicación dentro de esa máquina.

Controles

Elige un servicio y envía un paquete.

Servidor con varias aplicaciones

-aplicación destino
-socket origen
-socket destino
0paquetes enviados

Qué observar

  • La misma IP del servidor puede recibir tráfico de varias aplicaciones.
  • El puerto destino decide qué aplicación recibe los datos.
  • El protocolo también importa: TCP/53 y UDP/53 no son la misma conversación.
