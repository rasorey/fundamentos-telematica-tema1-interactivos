Mapa OSI frente a TCP/IP

Coloca protocolos y funciones sin forzar una correspondencia perfecta entre el modelo OSI e Internet real.

Controles

Asigna cada tarjeta a una capa OSI y a una capa TCP/IP.

Clasificación

Pilas de referencia

Qué observar

  • OSI ayuda a nombrar funciones; TCP/IP describe cómo se organiza Internet.
  • TLS y QUIC requieren matiz: no todo cae limpiamente en una sola capa introductoria.
  • Acceso a red agrupa funciones que OSI separa como enlace y físico.

Reto

Coloca DNS, TLS, TCP, IP y Wi-Fi y localiza el caso que necesita explicación.
