Qué observar

  • Para cada capa, lo que venía de arriba es la SDU.
  • La capa añade control y produce una PDU nueva.
  • Con payload pequeño, las cabeceras pesan más en el total.

Reto

Consigue que el overhead supere el 50 % con un dato de aplicación pequeño.
